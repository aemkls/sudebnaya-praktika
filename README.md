# Судебная практика — деплой на Streamlit Community Cloud

Эта папка — готовое к деплою Streamlit-приложение. Исходный HTML-файл (210 МБ)
был разобран на:

- `static/practice.html` — сама страница (шапка, поиск, JS) — теперь весит ~55 КБ;
- `static/data/offline-payload.b64` — поисковый индекс (темы, обстоятельства, карточки) — 34 МБ, подгружается при открытии страницы;
- `static/data/sources/<xx>/<uuid>.b64` — полные тексты ~21 800 судебных актов, каждый отдельным файлом (по паре hex-символов id в подпапке), подгружаются по клику «Полный судебный акт».

Ни один файл не превышает 100 МБ, поэтому **Git LFS не нужен** — обычный `git push` подойдёт.

Всё уже проверено локально (поиск, реестр, обстоятельства, открытие полного текста дела — работают без ошибок в консоли).

## Шаги деплоя

### 1. Распакуйте архив
Распакуйте `streamlit-deploy.zip` в удобную папку на компьютере.

### 2. Создайте репозиторий на GitHub
На github.com создайте новый **пустой** репозиторий, например `sudebnaya-praktika`
(можно приватный — Streamlit Community Cloud умеет деплоить и приватные репозитории
после привязки GitHub-аккаунта).

### 3. Запушьте код
В терминале, внутри распакованной папки `streamlit-deploy`:

```bash
git init
git add .
git commit -m "Судебная практика: поиск по делам"
git branch -M main
git remote add origin https://github.com/<ваш-аккаунт>/sudebnaya-praktika.git
git push -u origin main
```

Файлов много (~22 000), поэтому `git add`/`push` может занять несколько минут —
это нормально.

### 4. Деплой на Streamlit Community Cloud
1. Зайдите на https://share.streamlit.io и войдите через GitHub.
2. Нажмите «New app».
3. Выберите репозиторий `sudebnaya-praktika`, ветку `main`, главный файл — `streamlit_app.py`.
4. Нажмите «Deploy». Первый билд займёт пару минут.

### 5. Ссылка для руководителя
После деплоя приложение будет доступно по адресу вида:

```
https://<имя-приложения>.streamlit.app
```

На этой странице сразу будет кнопка «Открыть инструмент поиска по судебной практике»
и встроенная версия страницы. Эту ссылку и отправьте руководителю — она открывается
с любого устройства, локальный сервер не нужен.

## Если что-то пойдёт не так

- **Приложение «заснуло»** — на бесплатном тарифе Streamlit Community Cloud
  неактивные приложения останавливаются; первое открытие после паузы займёт
  10–30 секунд на «пробуждение».
- **Не проходит git push из-за размера** — маловероятно (ни один файл не больше
  34 МБ), но если провайдер/сеть режут большие пуши, отправьте несколькими
  коммитами (например, сначала `static/practice.html` и `data/offline-payload.b64`,
  затем `data/sources/` по подпапкам).
